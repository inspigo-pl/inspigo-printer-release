# Inspigo Printer — paczki instalacyjne

To repozytorium zawiera **wyłącznie paczki instalacyjne** aplikacji Inspigo
Printer. Kod źródłowy jest prywatny.

Aplikacja drukuje etykiety i dokumenty zlecone z panelu inspigo.cloud na
drukarce podłączonej do stanowiska.

## Pobieranie

Najnowsza wersja: [Releases](../../releases/latest)

| System | Plik |
| --- | --- |
| macOS (Apple Silicon i Intel) | `.dmg` |
| Windows | `.exe` |
| Linux | `.AppImage` (zalecany) albo `.deb` |

Plik dla macOS jest uniwersalny — ten sam dla procesorów Apple Silicon i Intel.

## Instalacja

Po instalacji uruchom aplikację i wklej **bilet parowania** wygenerowany
w panelu inspigo.cloud, w sekcji Integracje → Drukarki.
